## 3. ДИЗАЙН-СИСТЕМА

> Финальная сводка: цвета и значения радиусов/отступов — из YAML-файлов; шрифт заголовков — **Cormorant Garamond** (подтверждён); тело — **Inter**; UI — **Montserrat**.

### 3.1 Цветовая палитра

```css
:root {
  /* === ОСНОВНЫЕ (из Design System.YAML + blueprint.YAML) === */
  --clr-forest:      #2F4F3A;   /* PRIMARY: кнопки, акценты, иконки стихий, активное меню */
  --clr-olive:       #70835A;   /* SECONDARY: hover-состояния, второстепенные акценты */
  --clr-sand:        #D4B483;   /* ACCENT: разделители, лейблы, тонкие золотые детали */
  --clr-ivory:       #FAF9F5;   /* фон светлых секций */
  --clr-ivory-alt:   #F8F6F2;   /* фон чередующихся секций */
  --clr-white:       #FFFFFF;   /* основной фон страницы, текст на тёмном */

  /* === ТЁМНЫЕ (hero-оверлеи, footer, тёмная секция контактов) === */
  --clr-charcoal:    #222222;   /* тёмный фон секций */
  --clr-black:       #111008;   /* глубокий тёмный (hero-overlay) */

  /* === ТЕКСТ === */
  --clr-text:        #222222;   /* основной текст */
  --clr-text-muted:  #666666;   /* подписи, мета */
  --clr-text-light:  #FFFFFF;   /* текст на тёмном */

  /* === ОВЕРЛЕИ === */
  --overlay-hero:    rgba(0, 0, 0, 0.35);   /* hero: 35% (из blueprint) */
  --overlay-dark:    rgba(0, 0, 0, 0.55);   /* wedding banner: 25% */
  --overlay-wedding: rgba(0, 0, 0, 0.25);

  /* === РАДИУСЫ (из Design System.YAML) === */
  --radius-btn:    10px;   /* кнопки */
  --radius-card:   16px;   /* карточки домиков */
  --radius-img:    18px;   /* фото в секциях */
  --radius-gallery:12px;   /* фото в галерее */
}
```

**Правила применения:**
- **70%** — светлые фоны (`--clr-white`, `--clr-ivory`, `--clr-ivory-alt`).
- **20%** — природные фотографии.
- **10%** — акцентные цвета (`--clr-forest`, `--clr-sand`).
- PRIMARY-кнопка — `--clr-forest`; hover — `filter: brightness(1.1)` (+10%).
- Золото/песок `--clr-sand` — только тонкие линии-разделители и лейблы, не заливать им блоки.
- Тёмные секции (контакты, footer) — `--clr-charcoal`.
